# Tradingbot: live paper-trading track record

Automatically published paper-trading journals of four rule-based trading bots (crypto, Swedish stocks, US stocks, fund rotation). Live page: https://TimoWasTaken.github.io/tradingbot/

**Not investment advice. Paper trading only. Past results do not predict future results.**

The `data/` folder holds the raw journals as CSV (trades, equity, switches), regenerated daily.
