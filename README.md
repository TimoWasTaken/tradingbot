# Tradingbot: live paper-trading track record

Automatically published paper-trading journals of seven rule-based trading bots (crypto, Swedish stocks, US stocks, fund rotation, Polymarket, crypto 15-minute markets, copy-trading). Live page: https://timowastaken.github.io/tradingbot/
Source code: https://github.com/TimoWasTaken/tradingbot (branch `main`).

**Not investment advice. Paper trading only. Past results do not predict future results.**

The `data/` folder holds the raw journals as CSV (trades, equity, switches), regenerated daily.
